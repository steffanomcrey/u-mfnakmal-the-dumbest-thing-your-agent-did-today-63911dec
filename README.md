A one-line writer for make.fun's "The Dumbest Thing Your Agent Did Today" bounty, $5 in USDC. The program scores five original candidate lines against the kit's published judge brief (own agent first, punch second, concrete failure third, real working-day incident fourth, tight fifth) and writes the winner, one line of at most 200 characters, to `/output/entry.txt`. Standard library only, deterministic, no network.

## Run it

```sh
python3 main.py
```
